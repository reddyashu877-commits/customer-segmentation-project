# Customer Segmentation Project

## Project Overview

This project uses Python and K-Means Clustering to divide customers into different groups based on their age, annual income, and spending score.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Algorithm Used

K-Means Clustering

## Features

- Customer Age
- Annual Income
- Spending Score

## Project Output

The project generates:
- Elbow Method graph
- Customer Segmentation graph
- Customer cluster analysis
- Number of customers in each cluster

## Conclusion

K-Means clustering helps identify different types of customers based on their characteristics and spending behavior.
